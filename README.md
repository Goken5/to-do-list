# to-do-list
Aplicação onde o usuário pode criar uma lista de tarefas, lista de compras ou qualquer tipo de lista. <br>
Tecnologias Utilizadas: <br> 
Frontend em <strong>React</strong> com Typescript e TailwindCSS <br>
Backend com API utilizando <strong>Express</strong> e Typescript e banco de dados <strong>MongoDB</strong>
